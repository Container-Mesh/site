Documentation

ContainerMesh is a macOS menu-bar app for Docker Desktop. It discovers running containers and connects to them through ContainerTunnel. Names are optional. Networking starts only after you opt in.

The window lists containers. The menu bar remains after you close the window. From either place you can pause or resume, and open Settings, connection checks, and logs.

What you set up once

On first launch, Setup checks prerequisites. Containers stays behind Setup until those checks pass and you choose Enable automatic networking. Settings, connection checks, and logs stay available during Setup.

First launch walks through that choice. Names covers mesh.test and Compose-stack names.

What ContainerMesh leaves alone

  • Compose files stay as they are. Nothing here asks you to add a network or a port mapping.
  • There is no port list. You use the port the application already listens on.
  • A published name does not add TLS, and it does not change which host name an application accepts.

These pages describe how to use ContainerMesh. They do not include the application source. Product bugs belong in GitHub Issues. Security reports stay private.
