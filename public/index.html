macOS menu bar

Local names for the containers already running.

ContainerMesh discovers Docker containers and connects to them through ContainerTunnel. You choose which names to publish. Networking stays off until you explicitly opt in.

Read the docs First launch

Discover

Running containers appear on their own, including containers that are not in a Compose stack. There is no project to select and no port list to keep.

Name

The usual name is the container plus mesh.test. A Compose stack can be included. Any container can stay unpublished.

Connect

After you choose Enable automatic networking, ContainerMesh connects when it opens, and until you pause it.

Two names for the same container

Default
shop-web-1.mesh.test
With the Compose stack
shop-web-1.shop.mesh.test

Use the port the application already listens on. Port 80 is http://shop-web-1.mesh.test/. Port 5432 is db.mesh.test:5432.

Where it lives

The window lists containers. Closing it leaves ContainerMesh in the menu bar, where you can pause, resume, and open the window again.

The Snapfit mark is the joined C and M. Orange runs from #FF941F to #B8360B. The mark itself is ivory, #FFF4DD.

The connection is a choice.

Opening Docker Desktop does not turn networking on. Finishing the prerequisite check does not turn it on either. Automatic connection starts only when you choose Enable automatic networking.

Pause keeps the connection off across later launches. Quit disconnects for this session and leaves that saved choice for the next time the app opens.
