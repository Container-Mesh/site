# Security

Report a vulnerability privately:

https://github.com/Container-Mesh/site/security/advisories/new

Do not open a public issue for a security report. Public issues are for product bugs and for corrections to this site.

This repository is the public website and documentation. It does not contain the application. A private report can describe a problem in the macOS app, in ContainerTunnel as used by that app, or in this site.
