Troubleshooting

Docker is not running

Setup stays on Docker until the check passes. Choose Open Docker Desktop, wait until Docker is up, then Check again. Opening Docker does not opt in.

A prerequisite is not ready

Containers stays behind Setup. Connection checks names the failing item. Settings and logs remain available. Networking starts only after the checks are ready and you choose Enable automatic networking.

A name does not answer

  • The container is running, and its name is published rather than DNS off.
  • The connection is not paused, and the row is not still Waiting.
  • You are using the port the application listens on. The name does not add TLS and does not imply a different port.
  • The application accepts connections on its container address. An application bound only to its own loopback address will not answer.

A name or domain is rejected

Use a lowercase domain such as mesh.test. A label uses letters, numbers, and hyphens. The name field is that label, kept under the current domain.

The list is empty

The list is running containers on the selected Docker context. Start a container in Docker Desktop. While the connection is still being prepared, the window says so instead of showing an empty result as a finished list.
