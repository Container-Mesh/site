Bugs and security

Product bugs

Public issues on this repository are for bugs in the ContainerMesh app, and for corrections to this site. Open a product bug and include:

  • The macOS version
  • The version shown in About ContainerMesh
  • The Docker Desktop version
  • What you did, and what you expected

Leave out passwords, tokens, and private host details. Logs can contain local paths. This repository does not contain the application source.

Security reports

Security reports stay private. Do not open a public issue for a vulnerability. Use the private security report instead. The same request is in the repository security policy.
